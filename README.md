# Task Manager - Mini Project 2

This is a simple Task Manager Web Application made using HTML, CSS, and JavaScript.

## Features

- Add new tasks
- Display task list
- Mark tasks as completed
- Delete tasks
- Edit existing tasks
- Set task priority as low, medium, or high
- Filter tasks by all, pending, and completed
- Clear all completed tasks
- Save tasks in browser local storage
- Show total, completed, and pending task count
- Show daily progress percentage
- Responsive design for mobile and desktop
- Dynamic updates without page reload

## Technologies Used

- HTML
- CSS
- JavaScript

## Steps To Run The Project

1. Download or clone this project folder.
2. Open the `index.html` file in a web browser.
3. Type a task in the input box.
4. Select a priority.
5. Click the `Add Task` button.
6. Use the checkbox to mark a task as completed.
7. Use the filter buttons to view all, pending, or completed tasks.
8. Click `Edit` to update a task.
9. Click `Delete` to remove a task.

## How To Upload On GitHub

1. Create a new public repository on GitHub.
2. Upload `index.html`, `style.css`, `script.js`, and `README.md`.
3. Commit the files.
4. Go to repository `Settings`.
5. Open `Pages`.
6. Select the branch as `main`.
7. Save and wait for GitHub Pages to create your live link.
